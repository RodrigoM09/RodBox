# Generic examples

These are opt-in templates, not anyone's device backup. Keep personal config/progress private. Native PodBox progress supersedes legacy bookmark templates.

The menu template hides extra entries while preserving their data files. Update Now is a database action. Apply only deliberate settings; never overwrite a whole personal config.

## Optional Album Artist grouping

[`album-artist-menu.txt`](album-artist-menu.txt) is a single generic tagnavi row for grouping by Album Artist. Merge it into an existing valid menu; it is not a replacement device configuration and does not alter audio tags. Album-local `.artist/folder.jpg` sidecars can supply artist portraits separately from music files.
