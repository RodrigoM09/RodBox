# Bugs, errors and decisions

This record includes unsuccessful assumptions and rollback. AI helped inspect code and prepare fixes; it also needed evidence and correction.

- **Folder shortcuts versus a music library.** Browse shortcuts opened folders, not Artist/Album/Song views. The menu moved to the database-backed browser, and later to PodBox's native Music library. Shortcuts are retained as a generic example but hidden from the preferred main menu.
- **Cover Flow was the wrong interaction.** A separate carousel entry did not satisfy artwork inside the normal library. It was removed from the preferred menu. PodBox's artwork rows and cache supplied the wanted integration.
- **A theme file alone was insufficient.** The temporary Scrim Classic adaptation could not reproduce PodBox's custom transparency/rendering tags. Migrating to PodBox's app layer supplied the native renderer, with a known tradeoff: legacy plugins/games were optional and are not available through that app layer.
- **Volume and text overlays covered art.** Local Scrim edits reduced the intrusive volume presentation while retaining the native title/artist panel treatment. Custom labels also needed explicit glyph mappings.
- **Artwork lookup had several failure modes.** Internal volume prefixes caused mismatched art-cache keys; Unicode/normalization aliases needed care; some artists lacked Album Artist RAM entries. A bounded generation-invalidated first-track fallback avoids retagging whole libraries. Downloaded private artwork is not part of the repository.
- **Trash and AppleDouble files distorted the library audit.** Scans were restricted to Music/Audiobooks, excluding Trash. macOS `._` resource forks must not be counted as audio. The copy-test cleanup initially stopped because deleting a data file also removed its sidecar; cleanup was corrected to tolerate that automatic removal. No blind pruning follows an incomplete scan.
- **Headset edges were not reliable button holds.** Real trace observations informed bounded volume clicks, false-edge filtering and center-button classification. Multi-click skip was built around that decoder; blindly importing a generic decoder would regress it. Multimedia buttons were excluded from software long-press shutdown.
- **Book-to-shuffle kept the wrong queue.** Keep Current Track could keep the audiobook playlist when selecting Shuffle Songs. PB6 explicitly starts a fresh shuffled music queue while preserving ordinary Replace/Queue behavior and saving book progress first.
- **PB5 was rolled back.** After reconnect, a core FAT chain was inconsistent and old Trash links also needed repair. The cause was not proven. A supported filesystem repair and verified PB4 restoration preceded PB6. No format, bootloader, partition-layout or SysCFG change was used. The endpoint fix was later reintroduced separately as PB8 after accepted PB7 checks. A successful build had not proved storage integrity.
- **Six existing audio files were damaged or truncated.** Private archive copies repaired only the approved existing paths; intentionally deleted songs stayed deleted. Neither the media nor identifying filenames are published. File hashes prove copy identity, not original recording quality.
- **The first differential test generated impossible state.** Its rotated/shuffled boundaries produced UBSan diagnostics. The fixture was corrected, UBSan was set to halt on errors, and 50,000 comparisons then passed. The rejected run is not evidence of correctness.
- **A larger playlist redesign was unsuitable.** Upstream gap batching assumes a lock stays held, while PodBox can release it during context_yield. The small paired block move avoids exposing a temporary gap and adds no extra allocation.
- **Hardware identification is still a gate.** The Mac's attempted ATA/SAT query was unsupported. An iFlash label alone does not prove the existing generic SSD detector failed. Explicit brand detection remains research; no forced storage mode or new sleep delay was silently enabled.

Remaining uncertainty includes PB10 post-restart acceptance, long-term battery/wake behavior, actual adapter identity/classification and accessory/audio-output performance. These are not hidden behind passing host tests.
