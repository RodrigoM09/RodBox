# AI assistance and responsibility

OpenAI ChatGPT/Codex assisted with repository research, code reading, patch adaptation, test harnesses, artwork/library tooling, debugging and this documentation. Parallel AI agents audited checkpoint provenance and upstream credits. The device owner directed the feature choices and performed physical acceptance checks between isolated updates.

AI did not author Rockbox, PodBox, RockPod, Scrim or their inherited components. Their maintainers retain full credit. Some upstream commits separately acknowledge Cursor or Claude; those acknowledgments are retained in CREDITS.md rather than presented as local work.

AI-assisted hypotheses were checked against source, logs, build output, regression fixtures and user device reports. Some assumptions failed: see BUGS-AND-LESSONS.md. Synthetic tests and a successful build do not prove universal hardware compatibility, audio quality or battery gains. Missing historical evidence is labeled, not reconstructed as an invented original commit.

New publication commits use a neutral contributor identity to protect the device owner's information. This is an exported development record, not a claim that the neutral identity wrote every imported file. Original file headers, upstream references and licensing remain in place.
